# Importing Data from Tables on the Web to Excel

[![](images/b1553417-d041-4d3f-b580-6f569516ad84_1921x1025.png)](images/b1553417-d041-4d3f-b580-6f569516ad84_1921x1025.png)

Need to import a table from a website, but formatting and copying and pasting is a pain?

- Launch Excel
- Click on the Data tab and select Get Data — From Web

  [![](images/54da8576-deb9-4ed5-855e-b126449c4ae1_412x125.png)](images/54da8576-deb9-4ed5-855e-b126449c4ae1_412x125.png)

- Enter the website address that has a table. In this example, [Wikipedia](https://en.wikipedia.org/wiki/List_of_countries_and_dependencies_by_population)

[![](images/a568f4fc-50d7-4343-a1ea-8e6fb6c9db27_699x214.png)](images/a568f4fc-50d7-4343-a1ea-8e6fb6c9db27_699x214.png)

- Select the the table from the website you want to include and select Load

[![](images/ba146be6-fdd9-4090-84ec-5e8a9ca95eb3_876x694.png)](images/ba146be6-fdd9-4090-84ec-5e8a9ca95eb3_876x694.png)

- You’ve now got a perfectly formatted table that’s filtered and sortable.

[![](images/546e4b52-3490-437d-99ad-3f221a41bad6_1056x961.png)](images/546e4b52-3490-437d-99ad-3f221a41bad6_1056x961.png)

To ratchet up the awesomeness, it’s also possible to fetch data from websites you have access to that are behind a login.
