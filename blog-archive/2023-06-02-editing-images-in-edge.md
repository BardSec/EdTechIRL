# Editing Images in Edge

*Why download, open, and crop when you can just edit directly in the browser?*

There’s a new-ish feature in Edge that’s worth knowing about. Back in January, they rolled out the ability to edit images in the browser. If you’ve hovered over an image in Edge since then, you’ve probably noticed the visual search icon below that will let you do a reverse image search.

[![](images/af41e4c1-386c-4be2-b046-9a5b2381ba0f_882x604.png)](images/af41e4c1-386c-4be2-b046-9a5b2381ba0f_882x604.png)

However, you may not have noticed that if you hover over the visual search button and then move the cursor down slightly, you’ll get a hover context menu with options for editing the image.

[![](images/cacea17a-0643-49a6-a62e-4974b0ff2286_604x254.png)](images/cacea17a-0643-49a6-a62e-4974b0ff2286_604x254.png)

The main editing features are light, but enough to take care of a lot of basic editing needs. There are menus for Crop, Adjustment, Filter, and Markup, and rotate.
