# Troubleshooting Azure AD Error Codes

*Check AAD error codes in a flash*

[![](https://substackcdn.com/image/fetch/$s_!TUl4!,w_1456,c_limit,f_auto,q_auto:good,fl_progressive:steep/https%3A%2F%2Fsubstack-post-media.s3.amazonaws.com%2Fpublic%2Fimages%2Fcb2c0e1f-2365-4ccd-8dc1-04211e491a8e_1024x1024.png)](https://substackcdn.com/image/fetch/$s_!TUl4!,f_auto,q_auto:good,fl_progressive:steep/https%3A%2F%2Fsubstack-post-media.s3.amazonaws.com%2Fpublic%2Fimages%2Fcb2c0e1f-2365-4ccd-8dc1-04211e491a8e_1024x1024.png)

If you spend any time in Azure, bookmarking this site is a must:

<https://login.microsoftonline.com/error>

Pop in your error code, click submit, and it will explain the message and offer steps for remediation.
